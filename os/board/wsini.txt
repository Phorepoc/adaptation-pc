# The window server's screen modes of the PC board (the pdk's make_phorepoc_rom.sh adds these lines to wsini.ini).
#
# Two modes, as the phone's S60 has them: 1 = portrait 360x640, the display's own orientation; 2 = landscape 640x360, rotated
# 90 degrees. The screen driver of this board draws a rotated mode in software (registry/components_pc.py: the OMAP screen driver,
# whose draw devices support all four orientations), so the display keeps its 360x640 framebuffer. Twips are left out: the window
# server takes them from the display's pixel density (the HAL), rotated mode included.
#
# Hardware states (Avkon's layout config): the screen mode the display shows for an application that asks for no orientation, and
# the alternate mode it shows for one that asks for the other orientation (CAknSgcClient::DoCalculateScreenMode). The phone's S60
# has a portrait state (EKeyDeviceB, state 0) and a landscape state (EKeyDeviceA, state 1) that a sensor or a slide switches.
# This board's keyboard is a PC keyboard that SysAp reports as an open slide, and an open slide with a hardware QWERTY puts
# AknCapServer into the landscape state (CAknServKeyFilter::SlideStatusChangedL) -- on a PC that is no reason to turn the screen:
# both states show the same mode. A PC monitor is wide, so that mode is LANDSCAPE (mode 2) with portrait as the alternate: the
# screen boots landscape, an application that asks for portrait gets mode 1 while it is on top, and the Control Panel's "Screen
# orientation" (core gsphorient: S60's preferred orientation) makes portrait the default. The display turns with the mode
# (phescdv tells the kernel the draw device's orientation; xk_display.cpp turns the framebuffer), so the VM window is 640x360
# in landscape and 360x640 in portrait, upright both ways.
SCR_WIDTH1 360
SCR_HEIGHT1 640
SCR_ROTATION1 0
S60_SCR_STYLE_NAME1 QHDTOUCH
SCR_WIDTH2 640
SCR_HEIGHT2 360
SCR_ROTATION2 90
S60_SCR_SOFTKEY_LOCATION2 bottom
S60_SCR_STYLE_NAME2 QHDTOUCH
S60_HWSTATE_KEYCODE0 EKeyDeviceB
S60_HWSTATE_SCREENMODE0 2
S60_HWSTATE_ALT_SCREENMODE0 1
S60_HWSTATE_KEYCODE1 EKeyDeviceA
S60_HWSTATE_SCREENMODE1 2
S60_HWSTATE_ALT_SCREENMODE1 1
