# OURS (Phorepoc x86, 2026-10-12): the x86 drive map for ESTART (format: baseport/syborg/estart.txt). Before this file the

# the REAL efat32.fsy (sfat32), like the PinePhone's. Local drive 0 = the ATA disk's first partition (tools/phorepoc-x86/
# ekern/xk_media.cpp); without a disk (DISK=0) it is the RAM drive, formatted at boot (FS_FORMAT_CORRUPT: unformatted media).

F:  4  EFAT32  FAT   0       FS_NOT_RUGGED
